# Nubra — Assessment Submission

## Executive Summary
Nubra aims to simplify the shift from **manual trading to algorithmic trading** for retail users.
Our analysis shows that competitors provide strong tools for advanced users but fail to address **first-time automation adopters**.

We propose a **Rule-to-Strategy Wizard (R2S Wizard)** that enables traders to:
1. Enter their rule in plain language,
2. Preview parsed components,
3. Run a quick sandbox backtest, and
4. Progress gradually from manual → assisted → automated trading.

This approach emphasizes **trust, clarity, and explainability**, which are missing in existing tools.

---

## Competitor Analysis (Summary)
- **Zerodha Streak**: Beginner-friendly UI, but broker-locked and semi-automated.
- **Tradetron**: Scalable and cloud-based, but too complex for novices.
- **AlgoTest/QuantMan**: Options-focused, affordable, but steep learning curve.
- **Quantiply**: Low-latency infra, not retail-friendly.

**Gap:** None provide a guided, educational onboarding path for manual traders.

**Nubra’s edge:** Clear onboarding, trust-building microcopy, and broker-agnostic design.

---

## UI/UX Audit (Key Findings)
- Current dashboards feel cluttered, with **jargon-heavy navigation**.
- **No obvious entry point** for trying automation.
- Backtest outputs are table-heavy, with **no plain-language insights**.
- **Lack of inline guidance or educational snippets**.

---

## Recommendations
1. Add a **Start Wizard** button on the main dashboard.
2. Provide **plain-language backtest summaries** alongside metrics.
3. Embed **tooltips/micro-lessons** (e.g., “What does RSI < 30 mean?”).
4. Create a **progress tracker** (Manual → Assisted → Auto).

---

## Feature Proposal (Summary)
- **Rule-to-Strategy Wizard (R2S Wizard)**
   - Natural language rule parser
   - Guided parameter tuning
   - Sandbox backtesting
   - Exportable templates (JS/Python)
   - Progressive automation modes

---

## Conclusion
Nubra can position itself as the **first on-ramp into automation for retail traders**, capturing users that competitors overlook.
This strategic positioning, combined with actionable UX changes and a differentiated feature, makes Nubra’s offering **unique, credible, and practical**.
