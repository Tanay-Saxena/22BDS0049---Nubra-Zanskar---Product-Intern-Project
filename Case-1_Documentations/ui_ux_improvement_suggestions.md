# Nubra — UI/UX Improvement Suggestions

## High-Level Recommendations
1. **Clear entry point**
   - Add “Start Wizard” CTA directly on dashboard.
   - Highlight first action for new users.

2. **Trust-building backtest results**
   - Show results in plain English.
   - Example: “Triggered 20 trades last quarter, average profit 1.8%.”

3. **Micro-learning integration**
   - Tooltips: explain indicators (RSI, MACD, MA).
   - Short 1-line guides embedded in flow.

4. **Progressive automation**
   - Offer 3 modes: Manual, Assisted, Auto.
   - Helps traders build confidence gradually.

5. **Visual refresh**
   - Use modular cards instead of crowded tables.
   - Color-coded signals (green = safe, red = caution).

---

## Impact
- Reduces onboarding friction.
- Improves user confidence and trust.
- Differentiates Nubra from competitors by being **educational and approachable**.
